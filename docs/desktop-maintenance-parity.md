**Visual sign-off:** A compact dark-default workspace with a real list/gallery where it helps comparison, a stable table and details pane, searchable categories, keyboard and screen-reader flow, a persistent selection/review drawer, and useful empty, loading, error and partial states. Use real mixed data at 100%, 150% and 200% display scale. Measure shell launch, first useful data, full completion and input latency independently. Do not poll for work that can run once on entry or request. Do not hide work or delay results to improve benchmark numbers.

**First native integration point:** the existing Local Maintenance Agent offers the local-only [Storage Preview](../agent/README.md#storage-preview). It reports bounded aggregate metadata from one explicitly selected folder. It never deletes, moves or opens file contents, starts a listener, or sends results to a remote service. It does not yet render a storage UI, run on launch, provide a duplicate finder or apply cleanup. Integrate it as an explicit cancellable action in the native Desktop Storage surface; use the result status to prevent partial observations being displayed as complete.

**Done is device-tested:** Verify standard and elevated users, supported editions/policy ownership, x64 and ARM64 where shipped, offline use and known fault cases in disposable [Windows](https://www.microsoft.com/windows) fixtures before a repair is enabled. Ship Rescue only after real boot and restoration validation. Ship Mobile only after an enrolled device proves authenticated cross-client progress and explicitly permitted actions; a responsive website is not a native app.
