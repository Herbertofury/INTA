# INTA tool source register

Reviewed **November 26, 2026**. This register records official vendor/project documentation and the ATHENA research lineage behind the technician catalog. Source review is not a benchmark, installed-version check or certification of every executable. Download buttons intentionally lead to current official download pages or release channels instead of pinning an aging filename.

## Evidence and freshness

- **Core** means a practical starting point for the stated job, not measured superiority over every alternative.
- **Specialist** tools require a more specific investigation or deployment decision.
- **Evaluate** entries preserve useful ATHENA research without presenting experimental engines as proven antivirus replacements.
- The review date describes this documentation review. Confirm the publisher, architecture, release notes, signature/checksum and tool definitions when preparing a real job.
- A usable rescue ISO and the applications inside it have separate update lifecycles. Hiren's current official bundle lists older application versions; that bundle is not a claim that each included app is current.
- `source-checks.json` preserves unavailable source routes and successful official alternatives. A retrieval failure is not evidence that a product is unavailable.
