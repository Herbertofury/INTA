## Delivered catalog

The catalog contains **111 practical tools and entry points** across [malware removal](https://github.com/Herbertofury/INTA/wiki/Job-malware-removal), [remote support](https://github.com/Herbertofury/INTA/wiki/Job-remote-support), [Windows](https://www.microsoft.com/windows) diagnostics and repair, storage and backup, hardware testing, networking, bootable media, daily technician utilities, AI assistance and advanced defensive analysis. Each entry has a stable ID, job-focused description, best-use guidance, platforms, usage mode, pricing context, official download route, documentation, review date, tier, search tags and provenance.

**Core**, **specialist** and **evaluate** are editorial workflow categories. They do not assert measured detection or performance superiority. The catalog contains no invented newest-version numbers and makes no claim that all applications were installed or benchmarked here. Download routes use official current download pages or release channels.

## Verification and limits

The JSON was parsed and checked for unique IDs, required fields, supported tier/mode values, valid HTTPS URLs and absence of tracking parameters. Official primary-source documentation or current project pages were used for the tool descriptions. Failed direct retrieval routes were checked through alternate official pages or official repositories, and retained in `source-checks.json` as retrieval limitations rather than product-absence claims.

Some documentation endpoints require authentication or block automated retrieval. The catalog uses an accessible official evidence route for those entries; links such as the <a href="https://notepad-plus-plus.org/downloads/" title="Open Notepad++ official download or service page" aria-label="Open Notepad++ official download or service page" data-inta-brand="notepadplusplus"><img src="https://raw.githubusercontent.com/Herbertofury/INTA/main/assets/brand-icons/38c737fbe5283c8d9178.png" alt="Notepad++ official page" width="18" height="18" valign="middle" /></a> [Notepad++](https://notepad-plus-plus.org/) user manual can still be valid for a human browser despite an automated 403. No executable signatures, installer behavior, runtime compatibility or live boot-media image were validated by this research subtask. Those are separate acceptance gates for actual deployment.

The source register maps every entry to its official download and evidence. The catalog can be refreshed on demand without automatically changing client systems, replacing binaries, or scheduling background agents.
