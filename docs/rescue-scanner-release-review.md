# Review the Rescue scanner before a release

Boot or ISO checksum checks do not establish scanner safety. Both Rescue publication paths must read the actual <a href="https://www.debian.org/" title="Open Debian official download or service page" aria-label="Open Debian official download or service page" data-inta-brand="app-debian"><img src="https://raw.githubusercontent.com/Herbertofury/INTA/main/assets/brand-icons/98c05baf7fde67ee3abe.png" alt="Debian official page" width="18" height="18" valign="middle" /></a> [Debian](https://www.debian.org/) scanner package metadata from the same SHA-256-verified ISO they will publish. The test opens only two metadata files from the embedded SquashFS without mounting the image, booting it, executing the scanner, or reading a file supplied by a technician.

If the <a href="https://www.debian.org/" title="Open Debian official download or service page" aria-label="Open Debian official download or service page" data-inta-brand="app-debian"><img src="https://raw.githubusercontent.com/Herbertofury/INTA/main/assets/brand-icons/98c05baf7fde67ee3abe.png" alt="Debian official page" width="18" height="18" valign="middle" /></a> [Debian](https://www.debian.org/) stable package remains affected in the <a href="https://www.debian.org/" title="Open Debian official download or service page" aria-label="Open Debian official download or service page" data-inta-brand="app-debian"><img src="https://raw.githubusercontent.com/Herbertofury/INTA/main/assets/brand-icons/98c05baf7fde67ee3abe.png" alt="Debian official page" width="18" height="18" valign="middle" /></a> [Debian security tracker](https://security-tracker.debian.org/tracker/source-package/clamav), retain the ISO as a build candidate. A fresh candidate, release-package reconstruction test, mirror update, or a review for a different suite is not a substitute for the exact stable package review. Do not copy from unstable or weaken protections just to pass.

Only after the maintainer independently confirms that <a href="https://www.debian.org/" title="Open Debian official download or service page" aria-label="Open Debian official download or service page" data-inta-brand="app-debian"><img src="https://raw.githubusercontent.com/Herbertofury/INTA/main/assets/brand-icons/98c05baf7fde67ee3abe.png" alt="Debian official page" width="18" height="18" valign="middle" /></a> [Debian](https://www.debian.org/) stable supplies the fixed, signed packages, add `.github/rescue-scanner-review.json`. Include suite `trixie`, architecture `amd64`, source `clamav`, UTC `reviewed_on`, the <a href="https://www.debian.org/" title="Open Debian official download or service page" aria-label="Open Debian official download or service page" data-inta-brand="app-debian"><img src="https://raw.githubusercontent.com/Herbertofury/INTA/main/assets/brand-icons/98c05baf7fde67ee3abe.png" alt="Debian official page" width="18" height="18" valign="middle" /></a> [Debian](https://www.debian.org/) tracker and authoritative dated package provenance under `evidence`, and both exact installed package records under `packages`. Each record includes package, architecture, source, source version, and binary version. An absent or stale review, changed exact tuple, or the known affected package branch must fail the gate. No review is provided with this gate, and no candidate has been declared fixed.

After proving the gate, continue the existing BIOS/UEFI, recovery, checksum, and package reconstruction acceptance. Preserve earlier public releases for audit; do not replace one or announce an update until the current candidate qualifies.
