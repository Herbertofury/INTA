## ⚡ First three actions

1. Calculate the file hash locally and search for an existing report before sending file bytes to a service.
2. Compare detection names, report age, signer and behavior; choose a sandbox when you need to understand execution.
3. Record the exact hash and findings, then use the malware guide to verify the affected endpoint and choose cleanup or rebuild.

## 🧭 Match the symptom

| You see this | Do this next | You should get |
| --- | --- | --- |
| **The installed protection reports a threat** | Update through an approved channel, run its full scan and quarantine identified detections; retain the report. | The run has a completion state and a recorded action for every detection. |
| **Adware, unwanted extensions or browser redirection dominate** | Run <a href="https://www.malwarebytes.com/adwcleaner" title="Open Malwarebytes AdwCleaner official download or service page" aria-label="Open Malwarebytes AdwCleaner official download or service page" data-inta-brand="adwcleaner"><img src="https://raw.githubusercontent.com/Herbertofury/INTA/main/assets/brand-icons/4ed5ff877c2070a14163.png" alt="Malwarebytes AdwCleaner official page" width="18" height="18" valign="middle" /></a> [AdwCleaner](https://www.malwarebytes.com/adwcleaner), review its proposed changes and restore the intended browser extensions, search and notification settings. | The original browser task works and unwanted behavior does not return after restart. |
| **A second on-demand check is needed** | Download a fresh <a href="https://learn.microsoft.com/en-us/defender-endpoint/safety-scanner-download" title="Open Microsoft Safety Scanner official download or service page" aria-label="Open Microsoft Safety Scanner official download or service page" data-inta-brand="safety-scanner"><img src="https://raw.githubusercontent.com/Herbertofury/INTA/main/assets/brand-icons/4538691198fe0ea7526e.png" alt="Microsoft Safety Scanner official page" width="18" height="18" valign="middle" /></a> [Microsoft Safety Scanner](https://learn.microsoft.com/en-us/defender-endpoint/safety-scanner-download) from a clean PC, run a Full scan and read the detailed log. | Completed coverage, detections and unresolved items are recorded; a cancelled run is not marked clean. |
| **The same detection returns after reboot** | Inspect the relevant <a href="https://learn.microsoft.com/en-us/sysinternals/downloads/autoruns" title="Open Autoruns official download or service page" aria-label="Open Autoruns official download or service page" data-inta-brand="autoruns"><img src="https://raw.githubusercontent.com/Herbertofury/INTA/main/assets/brand-icons/4538691198fe0ea7526e.png" alt="Autoruns official page" width="18" height="18" valign="middle" /></a> [Autoruns](https://learn.microsoft.com/en-us/sysinternals/downloads/autoruns) entry and documented offline-scan prerequisites; use the rebuild decision if integrity remains uncertain. | The persistence cause is explained or a clean recovery plan replaces repeated scanner loops. |

### ✅ Finish the job

- [ ] Protection is healthy after reboot and there are no unresolved detections.
- [ ] The original task and browser behavior remain correct.
- [ ] Compromised accounts and sessions have a separate documented resolution.

**Change route when:** Ransomware, lateral spread or privileged access is suspected. · Detections recur or scan coverage and system integrity cannot be established.
