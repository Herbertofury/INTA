## 🧭 Match the symptom

| You see this | Do this next | You should get |
| --- | --- | --- |
| **The device is new or has a fresh installation** | Complete the approved enrollment and [Windows](https://www.microsoft.com/windows)/OEM updates, then check <a href="https://support.microsoft.com/en-us/windows/hardware/drivers/update-drivers-through-device-manager-in-windows" title="Open Device Manager official download or service page" aria-label="Open Device Manager official download or service page" data-inta-brand="app-device-manager"><img src="https://raw.githubusercontent.com/Herbertofury/INTA/main/assets/brand-icons/4538691198fe0ea7526e.png" alt="Device Manager official page" width="18" height="18" valign="middle" /></a> [Device Manager](https://support.microsoft.com/en-us/windows/hardware/drivers/update-drivers-through-device-manager-in-windows) for unresolved devices. | The intended identity and basic hardware work without unexplained device faults. |
| **Approved applications must be installed** | Use <a href="https://github.com/microsoft/winget-cli/releases/latest" title="Open Windows Package Manager (WinGet) official download or service page" aria-label="Open Windows Package Manager (WinGet) official download or service page" data-inta-brand="web-app-winget"><img src="https://raw.githubusercontent.com/Herbertofury/INTA/main/assets/brand-icons/4538691198fe0ea7526e.png" alt="Windows Package Manager (WinGet) official page" width="18" height="18" valign="middle" /></a> [WinGet](https://learn.microsoft.com/en-us/windows/package-manager/winget/) search/show to confirm package identity and review installation or the approved import list. | Each required app launches with the correct license and user context. |
| **Data comes from the previous device** | Copy the agreed data using the migration plan and test representative files in their real applications. | The user can access the expected files without relying on the old device. |
| **Setup is nearly complete** | Verify encryption recovery storage, a backup restore, printing and the user’s daily workflow before handoff. | The workstation is usable and recoverable, with acceptance evidence recorded. |

### ✅ Finish the job

- [ ] The owner can sign in and complete the agreed daily tasks.
- [ ] Recovery material and a tested backup are accessible through the approved private process.

**Change route when:** Enrollment, licensing or recovery ownership is unclear. · Migration would endanger the only copy of user data.
