### Inspect a suspicious link

Combine reputation with redirects and page behavior without opening the destination on the customer’s workstation.

<a href="https://urlscan.io/" title="Open urlscan.io official download or service page" aria-label="Open urlscan.io official download or service page" data-inta-brand="urlscan"><img src="https://raw.githubusercontent.com/Herbertofury/INTA/main/assets/brand-icons/27de5a5584035a1ad847.png" alt="urlscan.io official page" width="18" height="18" valign="middle" /></a> [urlscan.io](https://urlscan.io/) · <a href="https://transparencyreport.google.com/safe-browsing/search" title="Open Google Safe Browsing Site Status official download or service page" aria-label="Open Google Safe Browsing Site Status official download or service page" data-inta-brand="google-safe-browsing"><img src="https://raw.githubusercontent.com/Herbertofury/INTA/main/assets/brand-icons/4a3cfc17be3f4e8ad2c8.png" alt="Google Safe Browsing Site Status official page" width="18" height="18" valign="middle" /></a> [Google Safe Browsing Site Status](https://transparencyreport.google.com/safe-browsing/search) · <a href="https://checkphish.bolster.ai/" title="Open CheckPhish official download or service page" aria-label="Open CheckPhish official download or service page" data-inta-brand="checkphish"><img src="https://raw.githubusercontent.com/Herbertofury/INTA/main/assets/brand-icons/6af9ae40d5843099c148.png" alt="CheckPhish official page" width="18" height="18" valign="middle" /></a> [CheckPhish](https://checkphish.bolster.ai/)

1. Copy the destination as text and search existing reports; inspect the hostname before following a link.
2. For a new scan, choose a visibility mode suitable for the URL; use an existing report, hostname lookup or appropriate private workflow for a token-bearing link. Record any input redaction because it can change page behavior.
3. Compare redirects, page requests and reputation; follow the [incident guide](https://github.com/Herbertofury/INTA/wiki/Contain-ransomware) if someone entered credentials or downloaded a payload.
