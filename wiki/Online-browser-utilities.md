**Use for:** Move a selected service file between a phone and workstation when installing another application is unnecessary.

**Start here:** Open the service on both intended devices, verify the recipient or pairing code and send a harmless test file before the required copy.

**Read the result:** The recipient accepts and saves a matching file that opens correctly on the destination device.

**Access:** Free open-source service; self-hosting available No signup is required; pairing and transfer acceptance happen in the browser.

**Submission behavior:** Same-network transfers use a direct peer connection. Cross-network transfers may use a TURN relay; WebRTC encrypts traffic in transit, while the hosted signaling server still must be trusted.
