<a name="rufus"></a>

## Rufus

Writes bootable USB media from operating-system and recovery images.

**Choose it for:** Preparing one ISO on a dedicated USB drive.

**Platforms:** Windows · **Delivery:** portable · **Kit level:** Core

**Access / pricing:** Free / open source

[Official download](https://rufus.ie/#download) · [Documentation](https://github.com/pbatard/rufus/wiki/FAQ) · [Publisher](https://rufus.ie/)

> **Before you use it:** Writing media erases the selected target. Verify the drive identity before starting.

**Source:** https://github.com/pbatard/rufus/wiki/FAQ  
**Editorial review:** 2026-11-26  
**Selection provenance:** Official project or vendor documentation

## Ventoy

[Official download](https://www.ventoy.net/en/download.html) · [Documentation](https://www.ventoy.net/en/doc_start.html) · [Publisher](https://www.ventoy.net/)

> **Before you use it:** Initial installation formats the target. Updating Ventoy and replacing an ISO are separate operations; test boot compatibility.
