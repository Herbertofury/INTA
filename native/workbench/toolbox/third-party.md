# Toolbox source and license report

The four entries below are deployment overlays on existing INTA catalog IDs. Selection considered how useful the operation is without a network account, the strength of its integrity evidence, the availability of full source and license notices, the ability to run a bounded CLI test, and whether it duplicates an existing selection. Version-specific pins are recorded in [pins.json](pins.json). Packages remain in the local toolbox outside Git and outside the desktop installer.

- **restic 0.20.0, Core, encrypted backup.** The Windows amd64 portable restored original fixture bytes after a full repository data check. Its detached checksum signature validated against the public key fingerprint in the pinned installation guide. The project license is BSD-2-Clause. Preserve the copyright notice and disclaimer and review dependency notices for any redistribution. [Upstream license](https://github.com/restic/restic/blob/9c88ff768f10c192dc6a87619a65a16374080e33/LICENSE) · [Official release](https://github.com/restic/restic/releases/tag/v0.20.0)
- **rclone 1.76.0, Core, verified file transfer.** The amd64 executable copied a local fixture and checked the result by reading the destination bytes. No remote configuration or account was used. The upstream license is MIT. Keep its copyright and license text. The checksum file matches the separately pinned GitHub release SHA-256. It carries a legacy SHA-1 OpenPGP signature, insufficient as a modern release trust anchor. [Upstream license](https://github.com/rclone/rclone/blob/e982ff36668f5130d94b4f70409babb3d964df42/COPYING) · [Official release](https://github.com/rclone/rclone/releases/tag/v1.76.0)
- **7-Zip 26.06, Core, archive integrity.** The upstream standalone reduced 7zr executable is x86 and ran under Windows x64. It created, tested, and extracted a disposable 7z archive. The integrated operation tests a separate archive in a constrained worker. Upstream applies LGPL-2.1-or-later with file-specific BSD, public-domain and unRAR conditions for portions of the source. Both license documents accompany the local package. Distribution requires a component-specific obligations review, including corresponding-source requirements where applicable. [Upstream license](https://github.com/ip7z/7zip/blob/d3296e39e1f1f92c7b41c0c3848e65640428d42d/DOC/License.txt) · [Official release](https://github.com/ip7z/7zip/releases/tag/26.06)
- **YARA-X 1.25.0, Specialist, static file identification.** The Windows x64 scanner matched a benign fixture and gave no match for a negative control. The package includes the upstream BSD-3-Clause notice. Retain required notices and disclaimers and account for bundled dependencies. The scan fixture provides no evidence about malicious file detection coverage. [Upstream license](https://github.com/VirusTotal/yara-x/blob/ae2d36586f36726d268d634437ec23c701d941f2/LICENSE) · [Official release](https://github.com/VirusTotal/yara-x/releases/tag/v1.25.0)

## MangoDisk source review

The full MangoDisk v2.1.1 checkout is pinned at `d2a4fd6597524eb77b0687cfe1c9e6f533fae7c9`. Its Rust workspace declares GPL-3.0-only. It is a private source reference. No MangoDisk code, cleanup rules, assets or dependencies were incorporated into the INTA broker. The application does not expose a MangoDisk runtime or deletion control. [Upstream source](https://github.com/harry0703/MangoDisk/tree/d2a4fd6597524eb77b0687cfe1c9e6f533fae7c9) · [License](https://github.com/harry0703/MangoDisk/blob/d2a4fd6597524eb77b0687cfe1c9e6f533fae7c9/LICENSE)

Three design details informed the engineering review. The CMake rule describes its project marker, bounded relative directories, risk, and default selection. The root validator rejects traversal and absolute components. Duplicate-cache validation uses platform-level change monitoring and can invalidate cached conclusions. Its privileged protocol admits a small set of typed operations, bounds frames before allocation and validates request and response identity. INTA independently constrains its package index to relative paths and validates file bytes again immediately before launch.
